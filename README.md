## 📌 Overview

**AlertAura** is an **AI-powered Women Safety Companion Web Application** designed to support users during unsafe, uncomfortable, or emergency situations.

The application provides safety guidance, emergency support features, fake call simulation, AI-based assistance, and location-based safety support.

It acts like a smart virtual companion that helps users stay calm and take safer actions during difficult moments.

---

## 💡 Problem Statement

Women often face unsafe or uncomfortable situations in public places such as:

- Isolated streets
- Late-night travel
- Unfamiliar locations
- Public transport areas
- Empty roads or less crowded places

In such situations:

- Panic makes it difficult to think clearly
- Calling someone may not always be possible
- Finding nearby safe places quickly is difficult
- Most safety apps only provide basic SOS alerts
- Users may need emotional reassurance along with emergency support

There is a need for a smart safety assistant that can guide, support, and assist users in real time.

---

## ✅ Proposed Solution

**AlertAura** introduces an AI Safety Companion that acts like a trusted person during unsafe situations.

When a user feels unsafe, they can activate the assistant. The system can:

- Simulate a phone call
- Provide AI-based safety guidance
- Suggest safer nearby places
- Help the user stay calm
- Support emergency alert actions
- Guide the user step-by-step during stressful situations

## ⭐ Key Features

### 🆘 SOS Emergency Alert

- Quick emergency alert option
- Helps notify trusted contacts
- Designed for fast access
- Useful during unsafe situations

---

### 📞 AI Fake Call Simulation

The fake call feature helps the user appear busy or connected with someone.

Features include:

- Incoming call style interface
- Simulated call experience
- Safety-focused conversation flow
- Useful in uncomfortable public situations

---

### 🤖 AI Safety Assistant

The AI assistant gives safety-focused responses and emotional reassurance.

Example:

**User:**  
Someone is following me.

**AI Assistant:**  
Stay calm. Move towards a crowded or well-lit place like a shop, café, or security area. Avoid isolated paths and keep your phone ready.

## 🚀 How to Run Locally

### 1. Install Node.js

Before running this project, install **Node.js LTS** on your system.

Check installation:

```bash
node -v
npm -v
```

If both commands show version numbers, Node.js and npm are installed successfully.

---

### 2. Clone the Repository

```bash
git clone https://github.com/saibhavaniyedla/AlertAura.git
```

---

### 3. Move into the Repository

```bash
cd AlertAura
```

---

### 4. Move into the Project Folder

```bash
cd alertaura
```

---

### 5. Install Dependencies

```bash
npm install
```

This will install all required packages from `package.json`.

---

### 6. Start the Development Server

```bash
npm run dev
```

---

### 7. Open in Browser

After running the command, the terminal will show a local development URL.

Usually it will be:

```text
http://localhost:3000
```

Open that link in your browser to view the project.
